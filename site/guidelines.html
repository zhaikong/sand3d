Writing an assembly

Writing an assembly program

Eight rules for any program that builds a multi-part object in sand3d, by hand or by model. They were drawn from a review of generated asset and articulated programs, and have not been tested as a prompt. Every example is a real program, run under 1.4.0, when sand3d was still named sky3d. A fault is followed by how it should have been written: # ← comments are added to the original, and rewrites keep the original's shape.

  1. The head is the table of contents. First function, named after the object, no geometry.
  2. One function per distinct part. Built about its own origin; returns one object.
  3. Name each dimension once, derive the rest. Target 15 numbers per part, ceiling 40.
  4. Place each part once, in its parent's frame.
  5. Repeat with frames, mirror with a copy.
  6. Say each shape with the verb that names it. No bpy, no bmesh.
  7. Dress the parts when appearance matters. Optional on shape-only data.
  8. One frame per joint.

What a program looks like

A short head, then one function per part, each with its dimensions in its signature.

import sand3d as s3d


def floor_lamp():
    base = s3d.at(round_base(), z=-801)  # ← better: stand the stem on the base, derived from it
    stem = s3d.at(slender_stem(), z=-774)  # ← better: 27 above the base, not a second measured height
    return s3d.assembly("floor_lamp", base, stem)


def round_base(d=202, h=30, edge_r=6, collar_d=68, collar_h=9):
    base = s3d.cylinder("base", d=d, h=h)
    base = s3d.fillet(base, r=edge_r)  # ← accidental relation: the taper has nothing to do with the fillet
    collar = s3d.at(s3d.cone("collar", d=collar_d, d2=collar_d-edge_r*2, h=collar_h), z=h-1)
    base = s3d.join(base, collar)
    s3d.material(base, "painted_metal", color="#606060")
    return s3d.group("round_base", base)


def slender_stem(d=29, h=1419, shade_z=1300):
    stem = s3d.cylinder("stem", d=d, h=h)
    s3d.material(stem, "painted_metal", color="#595959")
    shade = s3d.at(open_shade(), z=shade_z)
    return s3d.group("slender_stem", stem, shade)

1. The head is the table of contents

The first function is named after the object. It builds no geometry: it calls the parts, places them and returns s3d.assembly. Runners call the first function, so the head comes first. Nothing at module level but the import. A detail that should stay deletable can hang on the assembly with attach, as in examples/chair.py; none of the 1 089 programs needed it.

2. One function per distinct part

A part builds about its own origin, takes what differs as arguments, and returns one object. Which one depends on how its pieces hold together:

the piecesthe verbwhat you get
fused for goodjoinone solid, one material: the first object's
separate, moving togethergroupeach piece keeps its mesh and its material
moving against each otherjointparts hung on frames, in the head (rule 8)

assembly is the top-level group, plus the anchors it publishes. One solid needs no group: return the solid. The trap: a lone solid placed inside its function loses that placement at the next at (z=50 then z=100 lands at 100, and in a group at 150). Build a lone solid at its origin.

Right: one function, three levers.

    lever1 = lever_part(150, "lever1", "#cc3333")
    lever2 = lever_part(120, "lever2", "#33cc33")
    lever3 = lever_part(100, "lever3", "#3333cc")

3. Name each dimension once, derive the rest

Main dimensions are keyword arguments in millimetres. A value measured on the target appears once. A value that follows from another is written as an expression of it.

  • Count the numbers. Target 15 per part, ceiling 40. A number is any numeric literal, keyword defaults included, except 0, 0.5, 1, 2, 45, 90, 180, 270 and 360. Clean programs have a median of 15, programs that fought the library 53.
  • Read every argument. 31.0 % of the programs declare a dimension they never read.
  • No if x == 28, no unexplained fraction. They hold only while the numbers around them stay put.
  • Expect to lose a little fidelity. Fewer numbers means a coarser match to a target. It is a trade.
  • Copying a value from a source is allowed, once. A joint origin copied from a URDF is a measurement.

Right: each point an expression of the arguments.

    profile = s3d.poly([(d/2,0), (d/2,shoulder), (mouth_d/2,h), (mouth_d/2-wall,h), (d/2-wall,shoulder), (d/2-wall,0)])
    neck = s3d.revolve("neck", profile)
    s3d.material(neck, kind="steel", color="#888888")

4. Place each part once, in its parent's frame

The head places the top-level parts with at, in the object's frame. Each part places its own children. A placement that follows from a dimension is written from it. The fault is a part built at its world position, then shifted back.

  • Prefer a frame when the relation is the point: on=ob.face("+Z"), bbox, local.
  • Every solid starts at z = 0, centred in x and y; extrude(both=True) centres it on its plane.
  • at sets the values it is given and keeps the others. transform moves by.

5. Repeat with frames, mirror with a copy

Copies go through on=s3d.grid(…), ring(…) or along(…). The other side of a pair is s3d.transform(s3d.copy(placed), mirror="x"). at is for a place, transform for a mirror image. Never cos and sin in a loop.

6. Say each shape with the verb that names it

A shape sand3d says in one verb is not written as a table of points. bpy and bmesh are forbidden: if sand3d cannot say a shape, open an issue for the missing verb. Free forms still resist: until sand3d has their verbs, a table may match a target better.

the shapethe verb
round about an axisrevolve(name, profile)
hollow, open on one sideshell(ob, t=…, open="top")
a bore, a bolt circlehole(ob, d=…, on=…)
a bent tubewire(name, path, d, fillet=…)
a section that changes along an axisloft(name, station(z, w, d), …)
a long body from its viewsbody(name, plan, top, bottom)
a band along a pathstroke(path, t)

station is the workhorse. It is a section at height z: width, depth, an offset x, y, and n from ellipse (2) to box (4). A few stations in a loft say a taper, a bulge or a drift.

Right: a nail, three stations and every value named.

def shaft(length=97.6, base_w=5.8, tip_w=4.0, base_h=6.5, tip_h=2.6, mid_w=4.7, mid_h=4.4, drift=-1.2, rise=0.4):
    solid = s3d.loft("shaft", s3d.station(z=0, w=base_w, d=base_h, y=-base_h/2, n=4), s3d.station(z=length/2, w=mid_w, d=mid_h, x=drift, y=-mid_h/2, n=4), s3d.station(z=length, w=tip_w, d=tip_h, y=-tip_h/2-rise, n=4))

7. Dress the parts when appearance matters

When the target has colours and materials, every part gets s3d.material(ob, kind, color="#rrggbb"), once, before it is repeated. On shape-only data, such as CAD pieces, it is optional.

  • On a group, material reaches every part with no material of its own. The nearest call wins.
  • join keeps the first object's material, group keeps each part's. Join only what is one colour.

Right: dressed before the grid.

    plank = s3d.box("top_plank", w=w, d=plank_d, h=h)
    s3d.material(plank, "oak", color="#5d4533")
    planks = s3d.at(plank, on=s3d.grid(nx=1, ny=5, py=pitch))

8. One frame per joint

In the head, f = s3d.local(parent, x, y, z) gives the pivot. The same f goes to s3d.at(child, on=f) and to s3d.joint(name, child, f, …).

  • Every joint sits in the head, frame, part and joint side by side, so a part comes off with its own lines.
  • local reads the parent's own space, however deep the chain. No coordinate is composed into the world.
  • axis is a direction in the space the parent lives in: "+X". A source's axis is turned by its rpy first.
  • The sign of the axis decides which way it opens. A positive value turns by the right hand about the axis. Of 23 drafts where a small edit made the joints right, 8 changed that sign and nothing else.
  • What does not move has no joint. Place it and put it in its parent's group before the joint is declared, or it stays behind when the parent moves.
  • Build at rest. Every joint at 0, no s3d.pose in the program.

Right: two slides and a hatch hinged on a sliding lid.

    left_f = s3d.local(cabinet, -350, 0, 900)
