sand3d 1.6.3

3D modeling in Python, built for LLMs

sand3d is a library for writing 3D objects as short programs: profiles, solids, edits, frames, joints and assemblies, over Blender's bpy. A program says how a shape is made, part by part and in its own words, so a model writes it in a few hundred tokens and a person can read it.

The sand3d programs are written for this repo, each matching its reference mesh. Objects that come as meshes are not compared: no program exists to set beside sand3d's.

A whole object, part by part

A front-loading washing machine: the cabinet, the drum, the door with its glass and handle, the drawer and the dial, each a named part, and four joints that say how they move.

door = s3d.group("door", ring, glass, handle)                      # the handle and the glass move with it
s3d.joint("door_hinge", door, hinge, axis="-Z", range=(0, 143))
s3d.joint("drum_spin", drum, front.move(0, 400), kind="continuous")
s3d.joint("drawer_slide", drawer, top_band.move(150), kind="prismatic", axis="+X", range=(0, 200))
s3d.joint("dial_turn", dial, top_band.move(-150), kind="continuous")
return s3d.assembly("washing_machine", cab, drum, door, drawer, dial, front=front)

Install, and a first program

Python 3.13 (recommended) or 3.11. Blender comes with it, as the bpy module: 5.2 LTS on Python 3.13, 4.5 LTS on Python 3.11; CI runs bpy 5.2.

pip install sand3d        # or, in a uv project: uv add sand3d
import sand3d as s3d


def bracket(w=80, d=40, t=6, hole_d=6.6, pitch=50):
    plate = s3d.extrude("plate", s3d.rect(w, d, r=4), t)
    s3d.hole(plate, hole_d, on=s3d.grid(2, 1, pitch, 0))
    s3d.fillet(plate, 1, edges="top")
    return plate

s3d.export(bracket(), "bracket.glb")

Give it to your LLM

Put the API in the system prompt: the rules of the vocabulary, every signature, and worked examples, in 3 643 tokens. It is served raw at api.md, and llms.txt points a model at it. For objects of several parts, the guidelines give the eight rules of an assembly program: the plan first, then the details, then the parts.

Datasets

sand3d programs for five sources of 3D objects, on Hugging Face under CC BY 4.0. The programs come from Sandflow's iterative agentic reconstruction pipeline, which will be described in upcoming releases.

sand3d-objaverse · Objaverse Everyday objects from Objaverse, each rebuilt as a program. sand3d-cad · CAD Mechanical parts from public CAD models. sand3d-articraft · Articraft Articulated objects from Articraft, their joints declared. sand3d-simready · SimReady Simulation-ready assets from NVIDIA SimReady. sand3d-automate · AutoMate Mechanical assemblies from AutoMate, each part a function of its program.
